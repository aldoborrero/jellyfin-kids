Kids

Mark the Jellyfin users who are kids. Kids get the kids mode of clients such as Wholphin, with the settings you choose here.

Users

Tick Kid for each child, then open their settings for screen time and the home screen.

Parent lock

The code grown-ups enter on a TV to leave kids mode or change its settings.

Set a code so grown-ups can unlock kids mode on TVs. Without one, only an administrator sign-in can change kids settings from a TV.

Screen time

Each kid's screen time starts again from zero at this hour, server time.
When a kid's allowance, sitting limit or allowed hours run out, the server warns them, stops the player and refuses new playback on every app, not only Wholphin, until a bonus, a break or the next day. An app that ignores the stop keeps playing what it has already downloaded, and DLNA players and offline downloads are out of reach.
How long a kid must have nothing playing for a new sitting to start, and how long they wait after reaching their sitting limit.
