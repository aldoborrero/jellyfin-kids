# Quickstart: validating live TV for kids

## 1. Dev loop

From the devshell, on a free port:

```sh
JELLYFIN_KIDS_DEV=$PWD/.dev JELLYFIN_KIDS_PORT=8196 dev        # builds, installs, starts, provisions
JELLYFIN_KIDS_DEV=$PWD/.dev JELLYFIN_KIDS_PORT=8196 scripts/dev-check.sh
```

Provisioning (research R12) also creates the live TV setup:

- the `livetv` process (`scripts/dev-livetv.sh`) serves two live MPEG-TS channels generated by jellyfin-ffmpeg over
  HTTP, on `127.0.0.1` ports `JELLYFIN_KIDS_PORT` + 10 (PekeTV) and + 11 (Grown-ups News); Jellyfin 12.2 only takes HTTP
  entries from an M3U;
- `.dev/livetv/channels.m3u`: "PekeTV" (1) and "Grown-ups News" (2);
- `.dev/livetv/guide.xml`: 30-minute programs for both channels for the next 48 h;
- an M3U tuner with stream sharing (so channels are served through `LiveTv/LiveStreamFiles`, as ErsatzTV's are) and
  an XMLTV listing provider, then a guide refresh; it waits until both channels and their programs exist.

## 2. dev-check (curl), sections `ca`–`cn`

| Check | Expected |
|---|---|
| Info | `liveTv` in `Features`, `LiveTv.Gate == "ok"` |
| Admin channel list | both channels, with number |
| PUT with a non-channel id / a duplicate | 400 `LiveTvChannelIds[i]` |
| PUT alice `["<PekeTV>"]`; GET profile | the list round-trips; omitting it on a later PUT clears it |
| alice PlaybackInfo PekeTV | media sources (a live stream opened) |
| alice PlaybackInfo News | 200 `NotAllowed`, `X-Kids-Reason: liveTvChannel` |
| alice `LiveStreams/Open` with News' open token (from the admin's PlaybackInfo) | 403 `liveTvChannel` |
| alice HLS `master.m3u8` of News; with PekeTV's id but News' admin-opened `LiveStreamId` | 403 `liveTvChannel` |
| alice `LiveTv/LiveStreamFiles/<unknown>/stream.ts` | 403 `liveTvChannel` |
| bob (no list) PlaybackInfo PekeTV | `NotAllowed` |
| alice with live TV access off | PekeTV `NotAllowed`; her channel list empty |
| admin, and an API key | both channels play |
| `EnforcementEnabled` off | the channel rule still refuses (always on) |
| alice `LiveTv/Recordings`, `LiveTv/Timers`, `POST LiveTv/Timers` | 403 `liveTvRecording`; admin 200 |
| alice `LiveTv/Channels` | PekeTV only, `TotalRecordCount` 1 |
| alice `LiveTv/Programs` (GET with and without `channelIds`, POST) and `Programs/Recommended` | PekeTV's programs only |
| alice `LiveTv/Channels/<News>`, `LiveTv/Programs/<a News program>` | 404 |
| alice `/Kids/Users/<alice>/LiveTv/Channels` | PekeTV with `CurrentProgram` |
| alice `/Kids/Users/<alice>/LiveTv/Programs` (default and with a window) | PekeTV's programs, ordered; bad window 400 |
| bob reads alice's channels | 403 |
| counting | alice plays PekeTV (Sessions/Playing with the channel id) for ~60 s: `UsedSeconds` grows by 60 ± 15 |

## 3. Counting with a real stream

With alice allowed PekeTV, play it in jellyfin-web (section 4) for two minutes, then read
`/Kids/Users/<alice>/Status`: `UsedSeconds` grew by about 120. With enforcement on and about a minute left, the time's
up message and stop arrive, and the live stream closes (`/Sessions` shows nothing playing; server log
"Live stream … closed").

## 4. Browser (jellyfin-web 12.2, headless Chromium)

A throwaway Playwright script (kept outside the repo) signs in as alice, opens Live TV → Channels, and:

1. sees only PekeTV in the channel list and the guide;
2. plays PekeTV: the video element advances for 10 s;
3. navigates to `#/details?id=<News>` and presses play: "Playback of this media is not allowed." appears and nothing
   plays.

## 5. Dashboard

Open Dashboard → Kids → alice: the "Live TV channels" section lists both channels with checkboxes; ticking PekeTV and
saving keeps it after a reload; with nothing ticked the "No live TV channels allowed" notice shows; turning off live
TV access for alice in her Jellyfin profile shows the warning.
